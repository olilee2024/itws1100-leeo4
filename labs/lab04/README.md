# itws1100-leeo4

In this lab, I created an rss feed and an atom feed. I used the same five articles from Times Articles, but I had to use different formats: RSS and Atom. In RSS I used the id tags channel, title, link, description, item, category, and pubDate. "Channel" describes the RSS feed and "item" was used for the specific articles. In Atom I used the id tags title, subtitle, link, id, updates, author, name, email, entry, and summary. Many have similarly named id tags. Here, "entry" is used for the articles.
