# itws1100-leeo4

For lab 03, I created a header that includes "olivia lee" page, projects page (with dropdown lan01, lab02, and lab03), and a extracurriculars page. In my "olivia lee" page I created it to be an about me page because it would be the first page users would see. So it's important for them to understand my passions, goals, and just to get to know me before moving on to other pages. 
Next, in my projects page, I included links to all the lab pages since in the future there will be plenty more labs and scrolling through one long page of labs wouldn't be efficient. So I created a dropdown menu on the navigation bar and I will add more lab pages once the semester progresses. 
In my extracurriculars page, I included pictures of extracurriculars I believed were important for user to see. Such as my art, UX Design wireframes, and coding experience. I included pictures and descriptions to show users the things I'm passionate about. 

The picture of my IA format in in the images folder in my lab03 (./images/iaformat.jpg). I chose to format my folders in a way that I can keep my lab folders separate and keep the specific css and images in those lab folders. For example in the lab03, I put all my css files (header, footer, and main) into it so that it focuses on the "personal website" aspect of the lab. For example in lab01 folder, I kept all the images in that folder because it pertains to that particular lab. I also put the projects.html in the labs folder because it is the homepage for all the labs.
