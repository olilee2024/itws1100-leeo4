In this lab we used javascript to make users fill out personal information about themselves through a form. Through the validate function in the javacsript file, we continue to add the errors if the user does not fill in the text area and sets focus is set to 1 or true to indicate that the focus is set, but if focusset is 0 (false) it will set the next element to 1. Additionally, to change colors we called functions from javascript in the div tag of the html. For example, "onclick = "javascript:recolor(this)" onblur = "javascript:restoreColor(this)"" to make it so that if the element is clicked on it colors it yellow and if clicked out it will turn back to the original color. And finally used the alert to print out the "Click me!" alert.
